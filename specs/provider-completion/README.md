# Provider completion

Close provider gaps through actual supported native interfaces and real accounts.
Construction and catalog discovery are distinct from model execution and accepted
application output. The existing four-language clients and transport remain the
execution contract. No provider, model, account or billing fallback is implicit.

## Implemented

- Gemini generation catalog eligibility follows declared `generateContent` support.
- Claude native application tools use the shared proposal-only MCP owner; the SDK
  retains validation, approvals and effects. Explicit native API billing is a
  separate isolated connection and guided setup offers the existing credential flow.
- OpenAI and Anthropic API tool/approval/streaming/usage checks passed from all four
  published clients. Anthropic content acceptance remains partial; see the
  [actual API evidence](../../docs/validation/api-tools-2026-11-05.md).
- API execution and discovery stop waiting for stalled credential resolvers after
  cancellation. Installed package and pure client contracts passed.
- Antigravity text execution uses an owned native execution gate. The same process
  proves a blocked, zero-usage control turn before application content. Read-only
  control files, deny-all hooks and strict native resource rules block actions;
  any native tool step fails the SDK run. A fresh installed SDK completed a real
  email task and rejected a native-write request. See the
  [installed qualification](../../docs/validation/antigravity-sdk-2026-11-06.md).
  Native tools, model discovery and execution each have one production owner;
  the operator probe reuses that owner instead of preserving the old catalog gate.

## Remaining work and genuine blockers

The selected Prometheus Claude subscription profile remains signed out. Grok's
reviewed native runtime still lacks a supported disabled-idle contract. Gemini/xAI
API execution needs an explicitly available selected credential. Broader platform
qualification and consumer upgrades remain separate from implementation.

Real active-inference cancellation and approval-denial qualification remains open:
the 2026-11-06 API attempt lost observations to a receipt-storage quota failure and
was not retried. Future qualifiers must persist request boundaries before moving
on and use a filesystem that enforces private ownership and permissions.

Antigravity's old advertised-tool mismatch is preserved as historical evidence,
not a blocker for the qualified replacement gate. The new route remains text-only
and unreleased. Continue from these remaining gates without weakening native
controls or treating successful model output as universal application acceptance.
